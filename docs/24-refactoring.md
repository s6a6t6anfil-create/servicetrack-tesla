# Рефакторинг інтерфейсу
Дата: 29.09.2026. Базова версія: e500ac9. Техніка Extract Function/Module.
1. input — генерацію підписаного поля перенесено з app.js у form-fields.js.
2. area — генерацію багаторядкового поля перенесено в той самий модуль.
3. select — генерацію списку та вибраної опції перенесено в той самий модуль.
Клієнт app.js імпортує три функції. Вміст HTML і правила escaping збережені. Новий регресійний тест перевіряє екранування тексту/атрибутів і selected; початкові п’ять тестів залишено. Це три фактично змінені фрагменти, а не опис майбутньої роботи.
Окреме функціональне виправлення: історія авто тепер проходить усі сторінки API; його не зараховано як рефакторинг без зміни поведінки.
