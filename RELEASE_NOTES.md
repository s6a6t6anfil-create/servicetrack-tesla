# ServiceTrack Tesla v1.0.0

Дата: 30.09.2026. Перший зафіксований навчальний реліз локального MVP для однієї незалежної майстерні Tesla. Версія не є підтвердженням виробничого приймання.

## Можливості

- Клієнти та автомобілі з унікальним VIN, пошуком і перевіркою зв’язків.
- Ремонтні замовлення, відповідальний механік, строк і сім статусів.
- Ручні записи діагностики та кодів несправностей, коментарі й історія дій.
- Позиції робіт і деталей, десятковий кошторис та закриття виданого замовлення.
- Ролі адміністратора й механіка, серверні перевірки доступу та CSRF.
- Україномовний адаптивний інтерфейс, OpenAPI, інструкції користувача й технічна документація.
- Ізольована демонстрація tools/demo.py зі штучними даними й випадковими локальними паролями.

## Виправлення

Усунено гонку завантаження карток, зависання стану завантаження після закриття діалогу, приховане повідомлення мережевої помилки, некоректні українські форми кількості, мобільну недоступність виходу та помилки обробки недопустимих ID. Виправлено нормалізацію VIN і старі синтетичні VIN у перевіреній демонстраційній базі; приватна база не поширюється. Рефакторинг API-клієнта зберігає зовнішню поведінку.

## Перевірка

30.09.2026: 32 backend тести й 22 JavaScript тести пройдено; інтеграційний протокол — 26 успішних операцій і 10 очікуваних помилок. Чистий експорт коду: міграції, seed чотирьох замовлень, вхід, список API та валідація OpenAPI пройшли; використано вже встановлене середовище залежностей. Журнали: docs/verification/pz36-*.

Браузерні докази ПЗ30 від 29.09.2026 охоплюють IAB/Chromium, Safari/WebKit і емуляцію 390×844. Зовнішній performance-аудит ПЗ25 датований 29.09.2026; його результати не є новим вимірюванням цього тегу.

## Відомі межі

Немає реального UAT, незалежного людського review, підтверджених репетицій або захисту. Не завершено повне випробування великих списків, граничних сум, конкурентних змін і production-розгортання. Високий desktop CLS у ПЗ25 та план оптимізації лишаються відкритими. SQLite не дає блокування рядків select_for_update. Перед реальними даними потрібні HTTPS, production WSGI, захист входу та перевірене резервування.

Склад, онлайн-оплата, автоматична діагностика й Tesla API/Toolbox поза MVP. Документи окремих ПЗ зберігають історичні стани; фінальні уточнення — у docs/30-final-check.md, docs/36-release.md та єдиному звіті.

## Відтворення

Завантажити Source code ZIP цього тегу або клонувати тег v1.0.0. Встановити requirements.txt у Python 3.12 та запустити `python tools/demo.py`. Докладні інструкції — README.md. Архів не містить робочої БД, .env, локальних паролів чи підписаного звіту студента.
